# shared rule validation

Date 2026-11-21. [Pull request](https://github.com/miksoleq/goldman-hackathon/pulls?q=is%3Apr+head%3Afeat/shared-rule-validation).

Control and Engine share v1 schema, condition paths and template syntax so accepting a rule in the editor predicts whether it can be loaded. A syntactically valid array index outside the supported array size resolves to no values.
