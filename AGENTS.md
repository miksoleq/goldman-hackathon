# Goldman Sachs Hackathon

This repository contains three independent instruction sets. Copy the **contents** of the relevant folder into the root of the corresponding repository so that its `AGENTS.md` applies there.

- [Backend](docs/backend/README.md): application architecture, API, storage, messaging and tests. Start with [backend instructions](docs/backend/AGENTS.md).
- [Frontend](docs/frontend/README.md): user interface, accessibility and testability. Start with [frontend instructions](docs/frontend/AGENTS.md).
- [E2E](docs/e2e/README.md): browser testing, Page Objects, scenarios and reporting. Start with [E2E instructions](docs/e2e/AGENTS.md).

Each set includes its own Git workflow, business rules and business-decision template. Coordinate shared contracts across repositories. The [technology options](docs/technology-options.md) are optional examples for planning the overall solution.
