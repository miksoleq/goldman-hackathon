# Event Monitor design

- **Color:** Use a restrained blue and slate palette: navy `#00355f`, blue `#7399c6`, white surfaces, and cool gray page backgrounds. Do not place a company name or logo in the interface.
- **Typography:** Prefer Goldman Sans when available, with Arial and sans-serif fallbacks. Use a compact 12–21 px scale and monospace for JSON payloads.
- **Layout:** Keep one dashboard with four tabs for Messages, Rules, Runbooks, and Alerts. On desktop, show a selectable list beside the selected record; on narrow screens, stack the panes.
- **Controls:** Use simple outlined refresh and tab controls, visible keyboard focus, restrained status colors, and text labels alongside status indicators.
